# КВС: сборка месячных отчетов

Два файла: app.py + requirements.txt.

## Деплой на streamlit.app
1. Создайте репозиторий на GitHub, залейте оба файла.
2. https://share.streamlit.io -> New app -> ваш репозиторий, main file: app.py -> Deploy.

## Локально
    pip install -r requirements.txt
    streamlit run app.py
